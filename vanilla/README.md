# JetSpace Landing - Vanilla Version

Полностью самодостаточная версия лендинга на чистом HTML/CSS/JavaScript без зависимостей.

## 🚀 Быстрый старт

Просто откройте `index.html` в браузере - всё работает без сборки!

```bash
# Или запустите локальный сервер
python3 -m http.server 8000
# Откройте http://localhost:8000
```

## 📁 Структура файлов

```
vanilla/
├── index.html          # Основной HTML файл
├── styles.css          # CSS стили (для разработки)
├── styles.min.css      # Минифицированный CSS (для production)
├── script.js           # JavaScript (для разработки)
├── script.min.js       # Минифицированный JS (для production)
├── assets/
│   └── logo.png        # Логотип
└── README.md           # Этот файл
```

## ✨ Особенности

- ✅ **Без зависимостей** - никакого npm, node_modules, сборки
- ✅ **Легковесный** - ~50KB для всего сайта (с минификацией)
- ✅ **Мультиязычность** - переключение RU/EN с сохранением в localStorage
- ✅ **Адаптивный дизайн** - работает на всех устройствах
- ✅ **Smooth scroll** - плавная прокрутка между секциями
- ✅ **Live счетчики** - анимированные статистики
- ✅ **Современный CSS** - градиенты, анимации, backdrop-filter
- ✅ **Cross-browser** - Chrome 90+, Firefox 88+, Safari 14+, Edge 90+

## 🌐 Переключение языков

Язык сохраняется в `localStorage` и восстанавливается при следующем визите.

```javascript
// Изменить язык программно
setLanguage('en'); // или 'ru'
```

## 🎨 Кастомизация

### Изменить цвета

Отредактируйте CSS переменные в `styles.css`:

```css
:root {
    --color-purple-500: oklch(0.627 0.265 303.9);
    --color-cyan-500: oklch(0.715 0.143 215.221);
    /* ... */
}
```

### Добавить новый язык

Добавьте в объект `translations` в `script.js`:

```javascript
const translations = {
    ru: { /* ... */ },
    en: { /* ... */ },
    es: { /* новый язык */ }
};
```

### Изменить ссылки CTA

Замените URL в функции `initCTAButtons()` в `script.js`:

```javascript
window.location.href = 'https://your-url.com';
```

## 🔧 Разработка vs Production

**Для разработки** используйте обычные версии в `index.html`:
```html
<link rel="stylesheet" href="styles.css">
<script src="script.js" defer></script>
```

**Для production** используйте минифицированные версии (уже настроено):
```html
<link rel="stylesheet" href="styles.min.css">
<script src="script.min.js" defer></script>
```

- Live счетчики работают только на клиенте (не синхронизированы с сервером)
